# Web Scraping and URL Discovery Tools

This folder contains Scrapy components for discovering Deriv website URLs:

- **ScrapyUrls.py** - Main spider for crawling Deriv website and extracting URLs
- **scrapy.cfg** - Scrapy project configuration file
- **scrapy_settings.py** - Spider behavior settings and crawling parameters

These tools generate the URL data that powers the application's dynamic routing system.
